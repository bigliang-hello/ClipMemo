# ClipMemo

极简的 macOS 剪贴板历史应用。

复制过的内容自动保存、随时搜索、一键粘回原处——不打扰,随叫随到。

## ✨ 主要功能

### 自动记录
- 文本、富文本(RTF)、图片、文件全类型监听
- 代码片段自动识别,列表内语法高亮
- 按日期智能分组:置顶 / 今天 / 昨天 / 近 7 天 / 近 30 天 / 更早

### 快速粘贴(核心体验)
- 任意应用内按 **⌘⇧V** 唤起轻量面板,不切换焦点、不打断输入
- 输入即搜索,**↑↓** 选择
- **⏎** 直接粘贴回原输入框 / **⌥⏎** 纯文本粘贴(去格式)/ **⌘⏎** 打开完整历史

### 来源追踪
- 每条记录标记来源应用(图标 + 名称),点击即筛选该应用的全部记录

### 隐私优先
- 数据全部本地存储,不上传任何内容
- 密码管理器标记的敏感内容(ConcealedType 行业约定)自动跳过,永不入库
- 应用排除名单:指定 App(已预置 1Password、Bitwarden)的复制永不记录
- 隐私模式:一键暂停监听

### 历史管理
- 全文搜索 + 类型筛选(文本 / 图像 / 文件)
- 置顶、编辑内容、删除、清空(危险操作二次确认)
- 容量控制:条数上限 + 7 / 30 / 90 天自动过期,置顶记录永不清理

### 其他
- 菜单栏常驻、开机自启
- 界面中英文即时切换、深色模式适配
- iCloud 同步(可选,默认关闭;需付费 Apple 开发者团队签名)

## ⌨️ 快捷键

| 快捷键 | 作用 |
|---|---|
| ⌘⇧V | 全局唤起 / 关闭快速粘贴面板 |
| ⌘K | 主窗口聚焦搜索框 |
| ⏎ | 粘贴选中条目 |
| ⌥⏎ | 以纯文本粘贴 |
| ⌘⏎ | 打开完整历史窗口 |
| Esc | 关闭面板 |

## 📦 安装

### 方式一:DMG

```bash
./Scripts/make-dmg.sh        # 产物:build/ClipMemo-<版本号>.dmg

# 可选开关(详见脚本头部注释):
ICLOUD=1 ./Scripts/make-dmg.sh    # 带 iCloud 同步能力(需付费开发者团队)
NOTARIZE=1 ./Scripts/make-dmg.sh  # Developer ID 签名 + Apple 公证 + 装订
```

打开 DMG,将 ClipMemo 拖入 Applications 即可。

首次使用快速粘贴时,按提示在 **系统设置 → 隐私与安全性 → 辅助功能** 中勾选 ClipMemo(用于把内容粘回原输入框)。

### 方式二:源码编译

```bash
xcodebuild -project ClipMemo.xcodeproj -scheme ClipMemo -configuration Release build
```

或用 Xcode 打开 `ClipMemo.xcodeproj` 直接运行。

## 🗂 目录结构

```
ClipMemo/
├── ClipMemoApp.swift    # 应用入口、菜单栏、全局命令
├── Models/              # 数据模型、Core Data 存储
├── Views/               # 界面(主窗口 / 卡片 / 设置 / 快速面板)
├── Services/            # 剪贴板监听、全局热键、多语言、来源应用
├── Resources/           # 图标、翻译、数据模型、签名权限
└── Scripts/             # DMG 打包等脚本
```

## 系统要求

- macOS 15.0 或更高版本
- 源码编译需 Xcode 26.5+
